Design notes and scope
  • This is a standalone visual proposal for issue #263, not a production UI change. Every reading, timestamp and job is sample data.
  • The “Modern polish” option adds softer depth, restrained gradients and clearer state emphasis while preserving the CC2 logo, navigation, core colors and existing content groups. Current CC2 remains available for comparison; dark, light and Obsidian palettes are included.
  • The same spacing and card tokens could later improve wide Settings pages, where the supplied screenshot shows excess unused space. This preview starts with Dashboard as requested in the maintainer discussion.
  • State, theme and viewport selectors change only this local mock. Action rows are non-interactive examples; nothing connects to or controls a printer.
  • The concept gives the active job the strongest hierarchy, keeps actions visible with their availability, and shows status changes only when the app observes a printer report.
  • Unknown reasons stay unknown; stale values are visibly marked. Existing polling, commands, action guards and the default layout are outside this preview.
  • The full card set uses responsive layout, visible text labels, keyboard focus and reduced-motion preferences for design review.
