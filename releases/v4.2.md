# Community Firmware V4.2 — CC2 Control 1.1.30

Community Firmware **V4.2** integrates **CC2 Control 1.1.30** and carries forward the validated V4.1/R8 persistent-storage startup fix.

## No additional post-install restart

> [!IMPORTANT]
> After the normal firmware update completes, no additional manual reboot or
> power-off/power-on cycle is required.

First-run LAN-code registration now restarts CC2 Control automatically and
realigns MQTT, Canvas and snapshot state without interrupting printer services.
If the page reports that synchronisation is taking longer than expected, wait
roughly 30 seconds and refresh it once.

## Highlights

### Bed Levelling

- one unified Bed Levelling sidebar entry
- mesh, saved Side A / Side B profiles, active mesh and four-screw measurement in one workflow
- four-screw corrections displayed in microns
- guarded Optimized reference adjustment suggestion
- advisory only: CC2 Control never turns or moves screws automatically

### Controls and safety

- operational Quick Actions: Home All, All Heaters Off, Fans Off and Motors Off
- global Emergency Stop visible on every page
- deliberate one-second press-and-hold required
- printer-state safety guards remain active

### Settings and appearance

- distinct Connection, Safety, Integrations, Appearance and About panels
- compact centered layout
- original Dark theme
- new persistent monochrome Light theme
- theme selection shared with OrcaSlicer

### Existing 1.1.26 improvements retained

- atomic nozzle/bed temperature application
- filenames with spaces
- UTF-8 G-code filenames
- file-manager multi-selection
- sequential bulk deletion
- streamed internal/USB copy
- Side A / Side B print workflow
- corrected `default` / `default1` mesh handling
- improved saved/adaptive/full-bed mesh states
- Canvas and thumbnail fixes

## Upgrade paths

### New installation / full update

Install Community Firmware V4.2 and allow the normal update boot to complete.

### Existing Community Firmware V4.1

You may install the CC2 Control 1.1.30 multiplatform package without reflashing
the full firmware. No additional printer restart or power cycle is required.

## Builder naming

The builder is derived from the validated V4.1/R8 line. Some internal script and directory names remain `v4_1` for continuity with the tested build chain. The release designation is **V4.2**.
