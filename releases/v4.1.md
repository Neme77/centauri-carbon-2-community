# Community Firmware V4.1 — CC2 Control 1.1.25

Community Firmware **V4.1** is focused on the full integration and stabilization of **CC2 Control 1.1.25** for the ELEGOO Centauri Carbon 2.

> [!IMPORTANT]
> **After the firmware installation has completed and the printer has booted normally, switch the printer completely off, then power it on again.**
>
> This post-install full power cycle is required so CC2 Control, Canvas state, MQTT registration and the background compatibility services initialize against a settled printer runtime.

V4.1 was validated with **two complete firmware installation cycles** before publication.

## Highlights

### CC2 Control integrated into the firmware
- CC2 Control 1.1.25
- Web dashboard on TCP 8081
- persistent configuration under `/opt/usr/cc2-control`
- firmware payload under `/opt/inst/cc2-control`
- original `elegoo_printer` kept unchanged

### OrcaSlicer Device integration
CC2 Control can be used directly in the **OrcaSlicer Device tab**.

The V4.1 workflow includes:
- dashboard and controls inside OrcaSlicer
- upload from OrcaSlicer
- upload-and-print
- Canvas spool-selection popup before print
- Canvas popup inside the Device view without requiring a manual refresh

### Dashboard and printer control
- live camera
- print state and progress
- nozzle and bed temperatures
- fan controls
- thermal history
- position and motion controls
- speed and flow
- lights, heaters and emergency actions
- memory, uptime, system load and MQTT/service status

### G-code file manager
- internal storage and USB browsing
- nested folders
- thumbnails
- print launch
- validated USB import before starting a job

### Canvas and materials
- four-slot Canvas detection
- load / unload
- material editing
- built-in and custom presets
- spool/material mapping
- multicolour spool-selection popup

### Bed Mesh and calibration
- 11×11 Bed Mesh
- 2D and 3D visualization
- screw measurement isolated from the stored mesh
- four-screw load-cell tramming

### Object Exclusion
Labelled multi-object prints can expose individual objects to CC2 Control and selected objects can be excluded with Klipper `EXCLUDE_OBJECT`.

### Protected expert console
The console uses an explicit unlock confirmation and is unavailable while printing.

Backend guards include:
- `G28` allowed before homing
- `G0/G1` blocked until X/Y/Z are homed
- tracked `G90/G91` positioning mode
- motion bounds checks
- low-level movement/stepper bypass commands blocked
- Klipper remains the final execution authority

### Panda / Moonraker-like compatibility
Compatibility service on TCP **7125** with support for:

```text
/server/info
/printer/info
/printer/objects/list
/printer/objects/query
/websocket
```

This is a deliberately limited compatibility bridge, not a full Moonraker replacement.

### Discovery API v1
A stable discovery/capability API is included so external projects can detect the Community Firmware, CC2 Control version, ports and supported capabilities without scraping the UI or exposing credentials.
