## Changes

- Retains root SSH, extended GUI Z-offset, Dual Trust v2, local HTTP and upload-during-print support from v3.7.
- Restores live OrcaSlicer temperature updates in WAN/cloud mode.
- Enables local webcam access while Matrix/WAN remains operational.
- Maintains tested WAN → LAN → WAN switching.
- Keeps the original four-client video limit.

The maintainer reports successful installation and operation, including restoration of stock firmware and subsequent installation of the modified firmware. Compatibility with other models or firmware bases is not established.

"Stock-signed" describes the update packaging, not unmodified content or vendor endorsement. This is modified firmware containing Dual Trust v2.

## Installation

1. Verify the SHA-256 against the attached checksum file.
2. With the printer idle, copy the .zip.sig file unchanged to USB storage. Do not extract it.
3. Use the printer's local USB update interface and maintain power until completion and reboot.
4. Verify normal operation after reboot.

Upload while printing depends on the client; use upload only, not print/start. No automatic print queue is added.

Read the [installation guide](https://github.com/Neme77/centauri-carbon-2-community/blob/main/docs/INSTALL.md). Keep the official recovery package available. Modified firmware is provided without warranty.
