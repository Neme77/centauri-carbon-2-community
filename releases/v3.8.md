# Centauri Carbon 2 Community firmware v3.8

Base firmware: **ELEGOO 02.01.00.00**  
Target: **Centauri Carbon 2 only**

## Highlights

- Retains root SSH, extended Z-offset, Dual Trust v2, local HTTP, and upload-during-print support from v3.7.
- Restores local MQTT/status access in WAN/cloud mode.
- Restores live OrcaSlicer temperature updates in WAN/cloud mode.
- Enables local webcam access while Matrix/WAN remains operational.
- Supports simultaneous local and Matrix video within the original client limit.
- Preserves tested WAN -> LAN -> WAN switching.

## Important

- The four-client video limit is unchanged.
- Verify the checksum of any installable artifact before use.
- The installable firmware and vendor-derived binary components are not stored in this source repository.
- Read `docs/INSTALL.md`, `docs/BUILD.md`, and `docs/TESTING.md` before installing or rebuilding.
