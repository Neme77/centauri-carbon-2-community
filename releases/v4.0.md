**Centauri Carbon 2 only — tested base: ELEGOO 02.01.00.00.**  
Independent community firmware; not an official ELEGOO release.

## Highlights

- CC2 Control 1.1.22 integrated into the firmware.
- Four-screw load-cell bed tramming at the physical screw positions, with three samples per point and front-left reference.
- Protected Klipper object exclusion for labelled multi-component prints.
- Temporary expert G-code terminal unlock: two warnings, exact phrase, five-minute memory-only token, idle-only execution, and homing guard for movement commands.
- Read-only Moonraker-compatible Panda Breath bridge on TCP 7125, hardware-tested with Panda Breath firmware 1.0.4.
- Correct 3D Bed Mesh X orientation and isolated screw capture, preserving the original 11×11 mesh.
- Clean-install browser setup asks for the printer LAN access code.

Existing dashboard, webcam, telemetry, thermal history, Canvas, material presets, protected controls, USB/internal printing, Z-offset, Dual Trust, SSH, and local upload features are retained.

## Installation

1. Verify the attached SHA-256 file.
2. With the printer idle and cool, copy the `.zip.sig` unchanged to USB storage.
3. Install it from the printer's local update interface and maintain power until reboot completes.
4. Open `http://PRINTER-IP:8081`, enter the LAN access code if prompted, and perform one complete reboot after setup.

Read the [full installation guide](https://github.com/Neme77/centauri-carbon-2-community/blob/main/docs/INSTALL_V4_0.md) and [CC2 Control documentation](https://github.com/Neme77/centauri-carbon-2-community/blob/main/docs/CC2_CONTROL.md).

## Important notes

- Object exclusion requires object labels in the sliced G-code.
- The Panda bridge exposes status only and cannot send G-code or control motion/heaters.
- A full firmware installation restores the root password from the firmware image. Run `passwd` afterward if you previously used a custom password.
- Keep the official recovery firmware available. Modified firmware is installed at the user's risk and without warranty.
